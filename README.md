# The Making Room

Diksha Singh's immersive AI creative portfolio.

**Open the website:** https://global0809.github.io/the-making-room-portfolio/

27 exhibits across infographics, AI images, podcasts, explainer films, AI songs, and an article. Every exhibit pairs the submitted asset with a detailed reconstructed prompt, creative decisions, and a critical reflection.

All prompts are newly written reconstructions; original prompt logs were not supplied. Suno playback opens through the five original supplied links.

The room is a custom Three.js implementation inspired by the warm office atmosphere of https://juliamoresco.com.br/. Sound is optional, reduced-motion preferences are respected, and all collections are available through the menu.

This repository contains the complete static website. GitHub Pages serves it directly from the main branch. Third-party licenses are retained in the fonts and vendor folders.
